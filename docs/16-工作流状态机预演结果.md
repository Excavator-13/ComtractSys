## 已修复缺陷 D1：多轮回退后会签阶段任务丢失

### 原最小复现

```
assign -> countersign(C1)->COUNTERSIGNED -> finalize -> reject(A1) -> resubmit -> return(A1,DRAFT) -> resume(DRAFT)
=> 状态 = ASSIGNED，但该轮没有任何 COUNTERSIGN 任务
```

### 根因

会签人名册在轮次推进时没有被所有路径持续携带：

- `resubmit()` 只克隆了 APPROVAL + SIGN，没有克隆 COUNTERSIGN。
- `resume(FINALIZE)` 只创建 FINALIZE 任务并克隆 APPROVAL + SIGN，没有克隆 COUNTERSIGN。
- `resume(DRAFT)` 又从 `previousRound` 读取 COUNTERSIGN 名册并激活。

当 `previousRound` 是由 `resubmit` 或 `resume(FINALIZE)` 进入的轮次时，该轮没有 COUNTERSIGN 行，恢复到 DRAFT 后就无法创建会签任务。

### 修复

在所有会把轮次推进到新轮次、但当前不激活会签的路径中，保留 COUNTERSIGN 的 SUPERSEDED 占位名册：

```java
cloneAssigneeTasksForNewRound(contract, previousRound, TaskType.COUNTERSIGN, "contract:countersign", false);
```

已覆盖：

- `ContractService.resubmit()`
- `ContractService.resume()` 的 `FINALIZE` 分支
- `scripts/workflow_sim.py` 的对应状态机模型
