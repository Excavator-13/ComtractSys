# 部署运行说明

更新时间：2026-05-21

## 1. 本地开发模式

后端默认使用 H2 内存数据库和 Flyway H2 脚本，适合快速开发和测试。

```powershell
cd backend
C:\maven\apache-maven-3.9.16\bin\mvn.cmd spring-boot:run
```

默认地址：

| 服务 | 地址 |
| --- | --- |
| 后端 API | http://localhost:8080 |
| Swagger | http://localhost:8080/swagger-ui/index.html |
| H2 Console | http://localhost:8080/h2-console |

前端开发：

```powershell
cd frontend
npm install
npm run dev
```

默认地址：`http://localhost:5173`。

## 2. Docker Compose 完整部署

完整环境包含 MySQL、Spring Boot 后端、Nginx 前端。

```powershell
cd backend
C:\maven\apache-maven-3.9.16\bin\mvn.cmd package
cd ..
docker compose up -d --build
```

服务端口：

| 服务 | 宿主机端口 | 容器端口 | 说明 |
| --- | --- | --- | --- |
| frontend | 5173 | 80 | Nginx 静态站点，并代理 `/api` 到后端 |
| backend | 18080 | 8080 | Spring Boot API |
| mysql | 3307 | 3306 | 本地 MySQL 联调端口 |

访问地址：

| 服务 | 地址 |
| --- | --- |
| 前端 | http://localhost:5173 |
| 后端 | http://localhost:18080 |
| Swagger | http://localhost:18080/swagger-ui/index.html |

## 3. 环境变量

Docker Compose 默认提供本地演示变量，生产环境必须替换密钥和数据库密码。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | `mysql` | Docker 后端使用 MySQL profile |
| `MYSQL_URL` | `jdbc:mysql://mysql:3306/contractsys...` | 后端容器内访问 MySQL |
| `MYSQL_USERNAME` | `contractsys` | 数据库用户名 |
| `MYSQL_PASSWORD` | `contractsys` | 数据库密码 |
| `JWT_SECRET` | 本地演示密钥 | JWT HS256 密钥，生产需替换为高强度密钥 |

MySQL profile 下数据库结构由 Flyway 管理，Docker 环境显式关闭 JPA DDL 自动建表和校验，避免 ORM 方言差异影响启动。

## 5. 运维与排障

查看服务：

```powershell
docker compose ps -a
```

查看日志：

```powershell
docker compose logs -f backend
docker compose logs -f frontend
docker compose logs -f mysql
```

停止环境但保留数据：

```powershell
docker compose down
```

如果需要重置本地演示数据库，可删除 Compose volume。该操作会清空 Docker 本地 MySQL 数据，仅用于开发环境：

```powershell
docker compose down -v
```

常见问题：

| 问题 | 处理方式 |
| --- | --- |
| 8080 或 3306 已被占用 | Compose 已映射为后端 18080、MySQL 3307 |
| 后端启动后无法连库 | 检查 `contractsys-mysql` 是否 healthy，查看 `docker compose logs mysql` |
| Flyway 校验失败 | 确认数据库脚本未修改已执行的版本；开发环境可重置 volume 后重试 |
| 前端 API 404 | 确认 `frontend/nginx.conf` 中 `/api/` 代理指向 `backend:8080` |
