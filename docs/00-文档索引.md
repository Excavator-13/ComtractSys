## 推荐实施顺序

1. 确认项目范围与技术栈。
2. 建立后端 Spring Boot 多模块或单体分层工程。
3. 建立前端管理端工程。
4. 先实现账号、权限、客户、合同起草。
5. 再实现分配、会签、定稿、审批、签订完整流程。
6. 最后补齐查询统计、日志、导出、测试和部署。
