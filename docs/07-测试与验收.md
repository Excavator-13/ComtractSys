# 合同管理系统测试与验收

## 1. 测试范围

| 类型 | 范围 |
| --- | --- |
| 单元测试 | 状态流转、参数校验、权限判断、编号生成 |
| 接口测试 | 认证、用户角色、客户、合同流程、日志 |
| 集成测试 | PermissionIntegrationTest：RBAC 权限边界全覆盖；BoundaryIntegrationTest：参数、认证、流程入口、附件边界、状态机回归 |
| 前端测试 | 路由权限、表单校验、列表查询、流程操作 |
| 安全测试 | 未登录、无权限、越权操作、文件上传限制 |
| 部署测试 | Docker Compose 启动 MySQL、后端、前端，并通过 smoke 脚本验证代理与核心接口 |

### 1.1 已有集成测试覆盖

`PermissionIntegrationTest`（位于 `backend/src/test/java/com/contractsys/auth/`）：

| 测试场景 | 验证点 |
| --- | --- |
| 管理员(admin) | 可访问合同/用户/角色/客户列表 |
| 管理员保护 | 不可删除、不可禁用 |
| 操作员(ROLE_OPERATOR) | 可访问合同/客户，不可访问用户/角色管理 |
| 合同管理员(ROLE_CONTRACT_ADMIN) | 可访问合同，不可访问客户/用户管理 |
| 新用户(ROLE_NEW_USER) | 所有受保护接口返回 403 |
| 内置角色保护 | 不可删除，名称不可修改（描述可修改） |
| 未认证访问 | 返回 401 |

`BoundaryIntegrationTest`（位于 `backend/src/test/java/com/contractsys/`）：

| 测试场景 | 验证点 |
| --- | --- |
| 注册登录边界 | 密码确认不一致、重复用户名、错误密码 |
| 用户/客户/角色校验 | 必填字段、重复角色编码 |
| 合同查询边界 | 非法状态返回 400，非正分页参数可归一化 |
| 合同创建边界 | 结束日期早于开始日期、未知客户 |
| 流程分配边界 | 分配给不存在用户返回 404 |
| 附件上传边界 | 空文件、非法扩展名返回 400 |
| 附件内容边界 | 文件内容与扩展名不匹配返回 400 |
| 协议边界 | 不支持的 HTTP 方法返回 405；Bearer 前缀大小写兼容 |
| 流程状态边界 | 多签订人全部完成后才进入 SIGNED |
| 越权修改边界 | 非起草人不可修改合同 |

运行命令：在 `backend` 目录执行 `mvn test`。当前通过 44 个用例。

## 2. 核心验收流程

### 2.1 注册登录

| 用例 | 预期 |
| --- | --- |
| 用户名为空注册 | 提示用户名不能为空 |
| 密码和确认密码不一致 | 提示确认密码不一致 |
| 重复用户名注册 | 提示用户名已存在 |
| 正确账号登录 | 返回 Token 和用户信息 |
| 错误密码登录 | 提示用户名或密码错误 |

### 2.2 权限管理

| 用例 | 预期 |
| --- | --- |
| 新用户注册 | 默认无业务菜单 |
| 管理员分配角色 | 用户重新登录后获得对应菜单 |
| 无权限访问用户管理 | 返回 403 |
| 删除角色前存在用户绑定 | 阻止删除或提示先解绑 |

### 2.3 客户管理

| 用例 | 预期 |
| --- | --- |
| 新增客户缺少名称 | 提示客户名称不能为空 |
| 新增客户缺少电话 | 提示电话不能为空 |
| 按客户名称模糊查询 | 返回匹配客户 |
| 删除已被合同引用客户 | 返回 409 或提示不可删除 |

### 2.4 合同流程

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 起草合同 | 状态为 DRAFT |
| 2 | 管理员分配会签/审批/签订人员 | 状态为 ASSIGNED，生成任务 |
| 3 | 会签人提交意见 | 对应任务 DONE |
| 4 | 所有会签人完成 | 状态为 COUNTERSIGNED |
| 5 | 起草人定稿 | 状态为 FINALIZED |
| 6 | 审批人全部通过 | 状态为 APPROVED |
| 7 | 签订人录入签订信息 | 状态为 SIGNED |

### 2.5 审批拒绝

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 合同进入 FINALIZED | 可审批 |
| 2 | 任一审批人拒绝 | 合同状态变为 REJECTED |
| 3 | 非审批人尝试审批 | 返回 403 |

### 2.6 文件上传

| 用例 | 预期 |
| --- | --- |
| 上传 doc 文件 | 成功 |
| 上传 jpg/png 文件 | 成功 |
| 上传 exe 文件 | 拒绝 |
| 下载附件 | 返回原文件 |
| 删除附件 | 仅有权限用户可删除 |

## 3. 非功能验收

| 项目 | 标准 |
| --- | --- |
| 响应时间 | 常规查询 2 秒内返回 |
| 数据一致性 | 流程操作必须事务提交 |
| 安全性 | 密码不可明文存储 |
| 易用性 | 主要流程不依赖手工输入用户 ID |
| 可维护性 | 接口有 Swagger 文档，数据库脚本可重复初始化 |

## 5. 缺陷等级

| 等级 | 说明 |
| --- | --- |
| Blocker | 主流程无法继续，如无法登录、无法审批 |
| Critical | 数据错误或权限越权 |
| Major | 重要功能异常但有绕行方式 |
| Minor | 展示、提示、样式问题 |
