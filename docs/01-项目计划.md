# 合同管理系统项目计划

## 1. 项目目标

建设一个基于 B/S 架构的合同管理系统，支持用户注册登录、角色权限管理、客户管理、合同起草、流程分配、会签、定稿、审批、签订、查询统计和操作日志。

系统默认采用 Spring 技术栈实现后端服务，前端采用现代 Web 管理端框架实现。

## 2. 项目范围

### 2.1 一期必须实现

| 模块 | 功能 |
| --- | --- |
| 账号认证 | 注册、登录、登出、当前用户信息 |
| 权限管理 | 用户管理、角色管理、功能权限、用户角色分配 |
| 客户管理 | 客户新增、查询、修改、删除 |
| 合同管理 | 起草、附件上传、管理员分配、会签、定稿、审批、签订 |
| 查询统计 | 合同信息查询、合同流程查询 |
| 日志管理 | 增删改、权限变更、流程操作日志查询 |

### 2.2 二期可扩展

| 能力 | 说明 |
| --- | --- |
| 合同模板 | 按模板生成合同正文 |
| 消息通知 | 待办提醒、站内信、邮件通知 |
| 文件预览 | Office/PDF 在线预览 |
| 导入导出 | Excel 导入客户、导出合同统计 |
| 电子签章 | 对接第三方电子签平台 |
| 流程引擎 | 接入 Flowable 或 Camunda 替换自研流程 |

## 3. 技术栈建议

### 3.1 后端

| 类别 | 技术 |
| --- | --- |
| 基础框架 | Spring Boot 3.x |
| 安全认证 | Spring Security + JWT |
| 数据访问 | Spring Data JPA 或 MyBatis-Plus |
| 数据库 | MySQL 8.x |
| 缓存 | Redis，可选 |
| 文件存储 | 本地磁盘开发环境，生产可切换 MinIO/OSS |
| 接口文档 | springdoc-openapi / Swagger UI |
| 构建工具 | Maven |
| 测试 | JUnit 5、Spring Boot Test、Testcontainers 可选 |

### 3.2 前端

| 类别 | 技术 |
| --- | --- |
| 框架 | Vue 3 + Vite 或 React + Vite |
| UI 组件 | Element Plus 或 Ant Design |
| 状态管理 | Pinia 或 Zustand/Redux Toolkit |
| 路由 | Vue Router 或 React Router |
| 请求 | Axios |
| 表单校验 | UI 组件内置校验 + 自定义规则 |

### 3.3 推荐架构形态

一期建议采用“单体分层架构”，即一个 Spring Boot 应用内按业务模块拆包。这样开发和部署成本更低，适合课程项目、新项目验证和中小型业务。

后续业务复杂后，可拆为认证服务、合同服务、客户服务、文件服务、日志服务。

## 6. 关键风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 合同流程状态不清晰 | 主流程容易出错 | 使用明确状态机和流程任务表 |
| 权限粒度过粗或过细 | 开发复杂或无法控制菜单 | 一期采用角色 + 权限点 |
| 文件上传安全 | 可能上传非法文件 | 限制类型、大小、随机文件名、隔离存储 |
| 并发审批/会签 | 状态更新冲突 | 使用事务和乐观锁 |
| 管理员业务权限边界 | 需求里提到管理员原则上只做管理 | 通过权限点控制管理员能否直接改合同 |
